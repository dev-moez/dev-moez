I build products with founders, hire and lead the engineering org, and own the stack from architecture to operations. I came up in the pre-YouTube era of solo learning — articles, forums, and hard-copy books across networking, cryptography, ethical hacking, and programming in Perl, C/C++, Python, PHP, and JavaScript — and was shipping rough little apps to friends before I knew what a software development lifecycle was.

What I learned along the way: **building software isn't writing code and shipping it.** It's thinking, designing the solution to fit the customer's problem, persona, and nature, and shaping the product around that. The code is the easy part.
